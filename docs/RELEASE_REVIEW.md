## 请用户最终检查

1. README 是否准确表达能力，尤其是beta、首次配置及不支持项。
2. 是否采用 `creator-ops` 作为仓库名、MIT作为许可证；当前署名为非个人化的 `Creator Ops contributors`，未放真实姓名、学校、手机号、邮箱或账号链接。
3. 公开包只有源代码、扩展、脚本、示例、测试、CI及说明。私人状态不打包；不要把源目录整体上传。
4. 接受 ACCEPTANCE.md 的未验证边界后，才授权创建公开仓库并上传。

只能从审核通过的ZIP重新解压到干净发布目录后初始化新的Git仓库。禁止沿用个人知识库Git历史；提交前复核作者邮箱/署名，使用经用户确认的公开标识或GitHub noreply。不得对整个个人知识库执行git add。上传后再检查远端文件列表、README和CI结果。
