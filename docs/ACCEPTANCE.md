- 标注为模拟的作品完成登记、合成Excel解析、飞书写入回读、重复运行不重新导出、72小时分析回写和未发送草稿入表。
- 五个未来精确任务及一个恢复任务在真实 Windows Task Scheduler 注册并回读；测试任务随后移除，未触发采集。
- 一条真实作品通过日常 Chrome 已安装的导出桥取得新 Excel，经候选版解析和隔离飞书表回读通过；如实记录为72小时节点的延迟补采。重复执行返回已完成，没有再次导出。未修改原生产表。

## 发布安全

审核包仅包含50个允许文件，逐文件SHA256和ZIP回读核验。运行配置、飞书资源ID、原始Excel、SQLite、作品素材、日志、缓存、私钥、聊天记录及Git历史均不进入压缩包。模式扫描加人工核对，不以模式扫描替代用户最后审核。

## 不冒充已验收的事项

- 没有另一台物理 Windows 电脑的账号端到端验收。
- 新用户手动加载本候选扩展后的真实登录验收尚未在另一浏览器配置中完成。本机真实导出使用已有导出桥；候选扩展新增的来源校验通过独立脚本测试。
- 没有在本候选包上等待同一新作品连续七天的五节点自然触发验收。
- GitHub CI 仅配置，用户批准上传后才能验证远端运行结果。
- 离线测试使用模拟依赖，不能替代真实网页登录、权限、浏览器扩展加载与平台变化测试。

因此适合以有边界的 beta 候选版提交发布审核，不应宣传“任意电脑零配置”“零bug”或“全部生产环境稳定”。
