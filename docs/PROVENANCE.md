# 来源与依赖

本项目从作者自用的 Windows 创作者工具中提取作品证据、资产归档、评论状态、Chrome 导出桥和 Excel 解析模块，并针对可移植性重构配置、调度、恢复和飞书适配。

架构参考项目：[TradingAi666/TzFilm-Douyin-Tool](https://github.com/TradingAi666/TzFilm-Douyin-Tool)。该项目的 macOS AppleScript 采集器、预测模型、会员引流与评论发送代码没有纳入本候选包。不宣称其测试、功能或成果属于本项目。

外部依赖：openpyxl（MIT）、et_xmlfile（MIT）、defusedxml（Python Software Foundation License）；飞书 CLI 独立安装，不随包分发。Python、Node.js、Chrome、PowerShell 需使用者自行安装并遵守其许可证。

候选许可证为 MIT，作者栏使用非个人化的 contributors 名称，最终随发布材料一并由用户审核。
